# TuTien2D / Trúc Khê

- **Project Unity:** [`unity/`](unity/README.md), Unity 6.3 LTS (6000.3.26f1), C#, khám phá top-down và combat ngang với bộ asset Bright Handheld hiện có.
- **Bàn giao và kết quả kiểm tra chuyển đổi:** [`unity/MIGRATION.md`](unity/MIGRATION.md). Nguồn đã chuyển và core đã kiểm tra; Play Mode/player build Unity còn chờ nghiệm thu bằng Editor.
- **Bản web nguồn:** [`game/`](game/README.md), giữ để tham chiếu và đối chiếu quy tắc/hình ảnh.
- **Nâng cấp Unity 6:** [`unity/UNITY6.md`](unity/UNITY6.md), phiên bản Editor/package và trạng thái kiểm tra.
- **Build Android/iOS:** [`unity/MOBILE.md`](unity/MOBILE.md), hướng dẫn APK/AAB và Xcode, cấu hình ký và trạng thái kiểm tra mobile.
- **Thư viện art nguồn:** `assets/`; dữ liệu thiết kế và lịch sử duyệt: `ai-workflow/`.

Để mở Unity, chọn thư mục **`unity`** trong Unity Hub, rồi mở `Assets/TrucKhe/Scenes/Main.unity` và bấm Play. Không cần chạy web server cho bản Unity.
